Version Labels

Adds quality and audio language information to the names shown in the version selector, in every Jellyfin app.

Placeholders that turn out empty are removed together with their separator.
Presets:
{name}Jellyfin's own version name (usually from the filename, e.g. "EN-NL")
{resolution}4K, 1080p, 720p, SD
{hdr}DV, HDR10+, HDR10, HLG, HDR (empty for SDR)
{videocodec}HEVC, H.264, AV1, ...
{audiocodec}Codec of the default audio track: TrueHD Atmos, DTS-HD MA, DD+, AAC, ...
{channels}Channels of the default audio track: 7.1, 5.1, Stereo, Mono
{languages}All audio languages: English, Dutch
{languagecodes}All audio languages as codes: ENG/DUT
{defaultlanguage}Language of the default audio track
{subtitles}All subtitle languages
{size}File size

Preview

Saves the current settings, then shows the version names exactly as the apps will receive them.
